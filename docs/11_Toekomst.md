# 11 — Toekomst

Tijdlamp is breder inzetbaar dan één museum. Dezelfde software kan nieuwe
contentpakketten draaien voor andere plekken en verhalen.

## Mogelijke toepassingen

- Brandweermuseum.
- Openluchtmuseum.
- Kastelen.
- Molens.
- Forten.
- Natuurgebieden.
- Spoorwegmusea.
- Stadswandelingen.
- Speurtochten.

## Hergebruik

Nieuwe projecten leveren eigen content, QR-labels, bronnen en media. De
software blijft gelijk zolang het contentpakket dezelfde standaard volgt.

## Randvoorwaarden

- Offline werking.
- Stabiele QR-ID's.
- Broncontrole.
- Eenvoudige SD-export.
- Beheertools voor niet-technische gebruikers.
