# Presentatie — Smalspoor hoofdstuk 1: Landschap en Tijd

vertical slice.

`smalspoor-h01-landschap`

`sdcard-example/shows/smalspoor-h01-landschap-demo/`

`sdcard-example/qr/smalspoor-h01-landschap.png`

- `smalspoor_h01_s04_heteren`

geen aparte JPEG-dia nodig.
